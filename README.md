# SĀRI Saree Boutique — Full Stack Demo
React + Vite + TypeScript frontend, Express backend, local real-photo-friendly image pipeline, 120 catalog products, search/filter/sort, cart, wishlist, product quick view, newsletter, and admin-ready API.

## Run
Backend:
  cd backend
  npm install
  npm run dev

Frontend (new terminal):
  cd frontend
  npm install
  npm run dev

Frontend: http://localhost:5173
API: http://localhost:5000

## Images
The project includes stable remote image URLs from Unsplash Source for fashion/editorial demo images. For a real store, replace them with your own or supplier-authorized product photography. Product records are designed so the image URL can be changed in one place.
